# TrackStudio

**Your trackpad, rearranged.**

TrackStudio is a macOS 13+ app that turns the whole trackpad into a visual control surface: edges for brightness, volume, and media; corners for actions; custom areas; per-app scenes; and haptics.

## What it is

A surface, not a trigger list. TrackStudio maps the trackpad itself:

- **Edges** — brightness, volume, media scrub.
- **Corners** — Mission Control, screenshots, new tabs, app actions.
- **Custom areas** — draw a control anywhere for undo, redo, or a repeated action.
- **Scenes** — a different layout for each app, with a default scene for everything else.
- **Haptics** — detents on the rails, ticks for actions, texture while scrubbing.

## What it is not

TrackStudio is not a scripting platform, a key remapper, or a full window manager. It is a focused trackpad surface made for people who want their Mac to feel more like a tool.

TrackStudio is not n-Track Studio, the TrackStudio issue tracker at trackstudio.com, or audio software.
